# Agentic Negotiator

A multi-agent AI negotiation platform where specialized Consumer, Producer, and Negotiator agents work together to reach optimal deals.

## Features
- Multi-agent architecture with Consumer, Producer, and Negotiator agents
- LLM-driven workflows that evaluate offers and generate counteroffers
- Outcome optimization based on satisfaction scores and constraints
- Scalable design for automated decision-making across business domains

## Project Structure
- backend/ - agents and negotiation logic (Python)
- frontend/ - HTML/JS user interface
- scripts/ - helper scripts
- init_db.py - database setup
